# Отчёт браузерной проверки

Дата: 25 октября 2026 года. Использованы уже установленные Chrome 155.0.8059.85 и Playwright из окружения рабочего компьютера; программы не устанавливались. Сервер запускался из собранного Go-файла во временной папке WSL. Это фактическая проверка Chromium, а не заявление о проверке всех браузеров.

Успешно проверены:

- Ширины 375, 768 и 1920 пикселей; у всей страницы нет горизонтального переполнения. Скриншоты узкого и широкого интерфейсов просмотрены.
- Генерация каждым из трёх шрифтов, рекомендация шрифта, выдача и применение вариантов текста.
- Настоящие загрузки через браузер: TXT, HTML, PDF, PNG и повторный TXT. Имя соответствует формату; TXT побайтно совпадает с `pre.textContent`; у PDF/PNG корректные сигнатуры.
- После пяти загрузок: TXT — 2, HTML — 1, PDF — 1, PNG — 1; всего — 5, обнаружен повтор содержимого, выдан совет по использованию.
- Пример `hello`/`standard`: 256 байт, 8 строк, ширина 31; оценки TXT 256, HTML 1440, PNG 14880; рекомендован TXT.
- Отдельный контекст браузера не получает статистику первой сессии.
- Слишком широкий PNG и слишком большой PDF дают 400 с объяснением. Ошибка PNG видна в интерфейсе, кнопка снова доступна. После неё широкий PDF успешно скачивается, `/healthz` отвечает 200.
- Необработанных ошибок JavaScript нет.

`browser-smoke.cjs` и `browser-edge-cases.cjs` находятся в `scripts/`. Они предназначены для окружения, где Playwright и браузер уже доступны. Путь к модулю/исполняемому файлу можно передать явно; скрипты не загружают браузер и не устанавливают пакеты.

Основной сценарий:

```sh
node scripts/browser-smoke.cjs http://localhost:8080
```

Снимки экрана необязательны; для них вторым аргументом укажите существующую папку. Третьим и четвёртым дополнительными аргументами можно передать путь к модулю Playwright и браузеру. Для дополнительного сценария аргументы: адрес сервера, путь к модулю, путь к браузеру.

Изображения и файлы загрузок, созданные при проверке, были временными. В репозитории сохраняются исходники проверок и этот текстовый отчёт.

## Независимая проверка PDF

Уже доступный `pdfjs-dist` прочитал экспортированный PDF и извлёк слова `one`/`two`. Рисунок из 301 столбца и 53 строк был прочитан как четыре страницы, все 15953 символа `x` сохранились. Размер скачанного документа совпал с `Content-Length`. Исходник дополнительной проверки — `scripts/pdf-inspect.cjs`; он не использует библиотеку, которой PDF создаётся.
