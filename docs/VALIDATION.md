## Что именно проверяют тесты

- Официальный пример `hello`: восемь строк по 31 символу, 256 байт, оценки 256/1440/14880. Границы ширины 120 и 121, приоритет ANSI-цвета, пустой ввод, CRLF, UTF-8 и дробная HTML-оценка 807,5 для трёх байт.
- Побайтовое совпадение TXT и исходного рисунка, включая пробелы и LF. HTML экранирует пользовательские теги, сохраняет первый LF и превращает обычные, яркие, 256-цветные и RGB ANSI-коды в управляемые стили.
- PDF проверяется по сигнатуре, завершающему маркеру, реальным смещениям объектов `xref` и тексту распакованных потоков. Проверяются экранирование скобок/обратного слеша и разбиение широкого и длинного рисунка на панели.
- PNG декодируется стандартным `image/png`; пиксели каждого символа сверяются с bitmap-таблицей. Проверяются предел по стороне и площади, пустой рисунок и удаление ANSI-кодов.
- HTTP-проверки проходят по реальным маршрутам через `httptest`: методы и `Allow`, формы, JSON, неизвестные поля и лишние объекты, предел тела, неверный UTF-8/percent-encoding, статические файлы и 404. Для всех четырёх форматов проверяются точный `Content-Length`, загрузочный `Content-Disposition` и безопасное имя файла.
- Разные cookie дают независимые счётчики; ошибочный экспорт не засчитывается. Параллельные загрузки и чтения статистики проверяются с `-race`; тест сессии выполняет 1280 конкурентных записей без потери счётчиков. Проверяются истечение часа, предел 1024 сессии и очередь 128 отпечатков рисунков.
- Перегрузка PNG/PDF проверяется заполненным семафором: API возвращает `503` и `Retry-After: 1`; успешная операция и ошибка содержимого освобождают место. Одновременно выполняются максимум четыре тяжёлых экспорта.
- Текстовые AI-функции проверяются в mock и с локальным тестовым HTTP-сервером, изображающим Ollama/OpenAI. Покрыты неверные ответы, недоступность, таймаут, отмена, ограничение и истечение кэша. Это проверка интеграционного протокола, без обращения к платной модели.

## Границы отчёта

Этот отчёт фиксирует выполненные программные проверки. Он не заменяет визуальную оценку в четырёх браузерах и не утверждает, что PDF был открыт независимой программой просмотра. Проверка файловых прав в браузере зависит от ОС и настроек загрузки: HTTP не передаёт POSIX-права, а сервер создаёт файлы в памяти без записи на диск.

Для повторения проверок после клонирования:

```bash
go test -race ./...
go vet ./...
go test ./... -cover
go test ./internal/export -run '^$' -fuzz '^FuzzBuildTextFormats$' -fuzztime=5s
go test ./internal/recommender -run '^$' -fuzz '^FuzzAnalyze$' -fuzztime=5s
```
