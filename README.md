# symbol-web-export

Это учебный веб-сервис для создания рисунков из печатных символов. Введите текст, выберите один из трёх шрифтов и скачайте результат. Проект показывает полный путь от HTML-формы до HTTP-ответа с файлом: генерацию, проверку ввода, выбор формата и обработку ошибок.

Владелец проекта: [Yernat Soltanbekov — GhostOfAstana](https://github.com/GhostOfAstana). Сервер и анализатор написаны на Go. Для интерфейса используются обычные HTML, CSS и JavaScript. Все функции доступны без регистрации. Проект подготовлен с помощью AI; материалы для разбора находятся в `docs/`.

## Быстрый запуск

Нужен Go 1.26 или новее. Другие программы, ключ API и база данных для обычной работы не нужны.

```sh
go run ./cmd/server
# Открыть http://localhost:8080
```

Команды выполняются из корня репозитория. Ресурсы встроены через `go:embed`: собранный исполняемый файл работает и из другой папки.

```sh
go build -o server ./cmd/server
ADDR=127.0.0.1:8090 ./server
go test ./...
go test -race ./...
go vet ./...
```

`ADDR` по умолчанию равен `:8080`. На публичном сервере TLS и ограничения общего трафика обычно настраиваются перед приложением. Тайм-ауты, ограничения запросов и корректное завершение уже есть в Go-сервере.

## Что умеет сервис

- Создаёт баннеры `standard`, `shadow`, `thinkertoy` из официальных файлов 01-edu.
- Экспортирует точный текст в TXT, самостоятельную HTML-страницу PDF для печати и PNG-изображение.
- Объясняет выбор TXT или HTML по правилам задания.
- Считает загрузки по форматам в текущей сессии, замечает повторный рисунок и предлагает оптимизацию.
- Предлагает продолжения текста, объяснимый выбор шрифта и творческие варианты. Без настроенной модели работает воспроизводимый демонстрационный режим.
- Показывает ошибки и состояние загрузки, поддерживает клавиатуру и небольшие экраны.

## Форматы и заголовки

| Формат | Что сохраняется | Content-Type |
|---|---|---|
| TXT | Исходные байты, включая пробелы, переводы строк и ANSI | `text/plain; charset=utf-8` |
| HTML | Экранированный текст в `<pre>`, обычные, 256-цветные и RGB ANSI SGR | `text/html; charset=utf-8` |
| PNG | Печатный ASCII, монохромный растровый шрифт 8×8; ANSI удаляется | `image/png` |
| PDF | Печатный ASCII, страницы и горизонтальные панели без переноса символов; ANSI удаляется | `application/pdf` |

Каждый успешный экспорт задаёт `Content-Length` как длину **готового массива байтов**, а `Content-Disposition: attachment` предлагает безопасное имя файла. Формула анализатора не используется вместо настоящего размера файла. HTML экранирует пользовательский текст и не исполняет вставленный JavaScript. TXT намеренно сохраняет введённые данные без изменений.

HTTP не передаёт Unix-права файла: права скачанного документа определяет браузер и операционная система. Не требуется административный доступ. Для явного сохранения с правами чтения и записи владельца предусмотрен `scripts/download.sh`; он выполняет `chmod 0644` после успешной загрузки. Сервер не пишет пользовательские файлы на диск и не создаёт гонку между одинаковыми именами.

Для PDF используется единственная внешняя зависимость `github.com/go-pdf/fpdf v0.9.0`, зафиксированная в `go.mod` и `go.sum`. У стандартной библиотеки Go нет готового средства создания PDF. Репозиторий библиотеки архивирован; здесь она применяется только к ограниченному тексту, без чтения чужих PDF или внешних ресурсов. Для основного генератора, TXT, HTML и анализа нужны только стандартные пакеты.

## Анализатор формата

`GET /export-analyzer?content=...` возвращает четыре показателя и три оценки размера:

| Оценка | Формула, байты |
|---|---|
| TXT | `len(content)` |
| HTML | `len(content) * 2.5 + 800` |
| PNG | `width * lines * 60` |

Число символов в JSON — **байты**, как требует ТЗ. Ширина — число Unicode-кодовых точек в самой длинной строке после удаления ANSI SGR. Это не ширина сложных Unicode-графем на экране. Завершающий LF не создаёт лишнюю строку; пустое содержимое даёт ноль строк и нулевую ширину. Для нечётной длины HTML-оценка может содержать `.5`; округления, не указанного в ТЗ, нет.

Порядок правил: ANSI-цвет → HTML; ширина больше 120 → HTML с предупреждением о переносе TXT; иначе → TXT. Это анализ по правилам, без нейросети. PDF доступен для скачивания, но не участвует в сравнении, поскольку ТЗ не задаёт для него формулу. PNG также доступен как дополнительный формат. Он создаётся стандартным `image/png`; встроенные данные шрифта находятся в Public Domain, их источник указан в `internal/export/font8x8.go`. Предел изображения — 4096 пикселей по каждой стороне и 4 Ми пикселей суммарно.

Официальный `hello` со шрифтом `standard` даёт 256 байт, 8 строк, ширину 31: TXT 256, HTML 1440, PNG 14880; рекомендация — TXT. Это проверяет автоматический тест.

## Запросы

| Метод и путь | Назначение |
|---|---|
| `GET /` | Форма и результат |
| `POST /symbol-art` | Поля формы `text` и `banner` |
| `POST /export` | Поля `content`, `format`, необязательный `filename`; форма или JSON |
| `GET /export?content=...&format=txt` | Небольшой экспорт через ссылку |
| `GET /export-analyzer?content=...` | JSON с показателями, оценками и объяснением |
| `GET /export-insights` | Статистика текущей cookie-сессии |
| `POST /api/suggest` | 3–5 коротких продолжений текста |
| `POST /api/recommend-banner` | Выбор шрифта без модели |
| `POST /api/variations` | Творческие варианты с описанием и шрифтом |
| `GET /healthz` | Проверка доступности сервера |

```sh
curl -f http://localhost:8080/symbol-art \
  --data-urlencode 'text=hello' --data 'banner=standard'

curl -f -D - http://localhost:8080/export \
  --data-urlencode 'content=Hello <world>!' --data 'format=html' \
  -o symbol-art.html

curl -f -G http://localhost:8080/export-analyzer \
  --data-urlencode 'content=hello'

curl -f -c session.cookie -b session.cookie http://localhost:8080/export \
  -H 'Content-Type: application/json' \
  --data '{"content":"hello","format":"txt"}' -o symbol-art.txt
curl -f -b session.cookie http://localhost:8080/export-insights
```

Установите `LLM_BASE_URL` и `LLM_MODEL`, чтобы включить реальную модель. По умолчанию используется протокол Ollama; `LLM_PROVIDER=openai` включает совместимый API. Подробности, кэш и примеры — в [TEXT_AI.md](TEXT_AI.md) и [.env.example](.env.example). `.env.example` — справка: сервер читает переменные окружения, а не автоматически загружает `.env`.

## Ограничения и отказоустойчивость

PNG и PDF одновременно выполняются максимум в четырёх запросах: при перегрузке ответ 503 с `Retry-After: 1`. Один исходный текст ограничен 4096 байтами; экспортируемый рисунок — 128 КиБ; тело формы или JSON — 1 МиБ. Контрольные символы и неподдерживаемые шрифты не попадают в генератор. В TXT и HTML можно передавать корректный UTF-8; PDF поддерживает только печатный ASCII и до 64000 ячеек, максимум 256 панелей/страниц. PNG поддерживает печатный ASCII и те же монохромные рисунки в пределах растровых ограничений. Ошибка PDF не мешает выбрать TXT или HTML.

Сессии хранятся в памяти один час: максимум 1024 сессии и 128 хешей рисунков на сессию. В счётчики попадают успешно подготовленные ответы экспорта. Сервер не может установить, нажал ли человек «Сохранить» в браузере. При перезапуске статистика очищается; для нескольких экземпляров сервера нужен общий внешний store. Cookie имеет `HttpOnly`, `SameSite=Lax` и `Secure` при HTTPS. Браузерный код показывает сведения только как текст.

Тайм-аут модели — 10 секунд; нет неограниченной очереди. Недоступный backend возвращает 503, повреждённый ответ — 500, неверный ввод — 400, неподходящий метод — 405. Сервер проверяет ресурсы при запуске и завершается с понятной ошибкой, если сборка повреждена.

## Структура

```text
cmd/server/                 запуск, тайм-ауты, завершение
internal/ascii/             чтение шрифтов и генерация
internal/export/            TXT, HTML, PDF, PNG
internal/recommender/       показатели и правила формата
internal/insights/          ограниченная статистика сессии
internal/handlers/          маршруты, формы, ответы
internal/textai/            подсказки, варианты и рекомендация шрифта
templates/                  index.html, result.html, export.html
static/css/, static/js/     оформление и взаимодействие
docs/                       карта аудита, ответы и проверки
scripts/                    сохранение файла с явными правами
standard.txt, shadow.txt,
thinkertoy.txt              официальные шрифты
```

Происхождение шрифтов и контрольные суммы: [FONTS.md](FONTS.md). Карта проверок: [docs/AUDIT.md](docs/AUDIT.md). Разбор для защиты: [docs/AUDITOR_QA.md](docs/AUDITOR_QA.md). Выполненные проверки: [docs/VALIDATION.md](docs/VALIDATION.md) и [docs/BROWSER-REPORT.md](docs/BROWSER-REPORT.md); результаты фиксируются отдельно, без обещания, что конечный набор тестов исключает все возможные ошибки.
